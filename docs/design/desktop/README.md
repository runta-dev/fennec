# Desktop window mockup

Interactive mockup of the Fennec for Mac desktop window: projects with request
boards, sessions with terminal tabs, project settings, organization switcher and
search. Sample data only; nothing is saved. The design is described in
[`../../desktop-app.md`](../../desktop-app.md).

```sh
npm install
npm run dev   # http://127.0.0.1:5188
```

Useful routes: `#agent-a3` (a session), `#new-session`,
`#settings-fennec-general` (also `-knowledge`, `-queue`, `-agents`), `#new`
(composer with a draft).
